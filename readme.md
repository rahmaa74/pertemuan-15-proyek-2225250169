## Cara Menjalankan Program

1. Pastikan Python sudah terinstal.
2. Buka folder proyek melalui VS Code.
3. Buka Terminal.
4. Jalankan perintah:

   python main.py

## Cara Menjalankan Pengujian

Jalankan perintah:

   python -m unittest discover -s tests -v

## Hasil Pengujian

Program diuji menggunakan 5 pengujian otomatis, meliputi:
- Perhitungan rata-rata.
- Penentuan nilai tertinggi.
- Penentuan nilai terendah.
- Penentuan kelulusan.
- Penanganan data kosong.
